# Responsive Contact Form

A responsive contact form built as Task 2 of the Elevvo Frontend Development Internship.

## Features

* Full Name, Email Address, Subject, and Message fields
* Responsive layout for different screen sizes
* Custom JavaScript validation for empty fields
* Email format validation
* Interactive submit button with a hover effect

## Technologies Used

* HTML5
* CSS3
* JavaScript

## What I Learned

* Structuring accessible HTML forms
* Styling forms with CSS Flexbox
* Creating responsive layouts
* Handling form submission events with JavaScript
* Validating user input

## Note

This project demonstrates client-side form validation. It does not send messages to a server.
